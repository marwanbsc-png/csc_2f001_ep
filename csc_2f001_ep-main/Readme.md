# Presentation

The purpose of this course is to give practical knowledge of C and C++.
The first 7 weeks are devoted to learning C and C++ (1.5 hours of lectures and 2 hours of exercises per week).
During the 7 remaining weeks, students work in groups of 4 on a project.

The subjects covered range from imperative programming in C to object-oriented programming in C++:
* Imperative programming in C (types, arrays, structures, and functions)
* Pointers and memory management in C
* From source code to execution (compilation, linking, libraries, Makefiles, processes, and debuggers)
* Classes, constructors, destructors, and inheritance in C++
* Pointers, references, and operator overloading in C++
* Templates in C++
* Introduction to the C++ standard library

The final grade is determined by graded labs (10%), an exam at the end of the 14th week (50%), and an individual project evaluation (40%).
Before starting the labs, you must install your development environment by following the instructions here.
